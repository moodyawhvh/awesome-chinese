## 什么是 Awesome 清单?

Awesome 清单是经过社区筛选、持续维护的优质资源汇总,每个条目附一句话说明,覆盖某个技术领域或兴趣主题。本项目是所有 Awesome 清单的"总目录"。想深入了解可阅读原仓库的 `contributing.md`(贡献指南)与 `create-list.md`(如何创建自己的清单)。

## 平台

各操作系统与运行时平台的开发资源:

- [Node.js](https://github.com/sindresorhus/awesome-nodejs#readme) - 构建在 Chrome V8 之上的异步事件驱动 JavaScript 运行时。

- [Android](https://github.com/JStumpp/awesome-android#readme) - Google 开发的移动操作系统。
- [macOS](https://github.com/jaywcjlove/awesome-mac#readme) - 苹果 Mac 电脑操作系统及其应用合集。

- [Flutter](https://github.com/Solido/awesome-flutter#readme) - Google 的移动 SDK,用一套 Dart 代码构建原生 iOS/Android 应用。
